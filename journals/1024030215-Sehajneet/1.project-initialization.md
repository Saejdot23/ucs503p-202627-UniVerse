# Week 1: Project Initialization & Data Model Design

## Project Initialization

### Objective

The primary goal of Week 1 was to establish the initial foundation for the **UniVerse** project. The work focused on understanding the project requirements, setting up the development environment, planning the system structure, and designing the database model.

UniVerse is a campus-focused platform designed to connect students through **skill exchange, mentorship, lending/borrowing, and lost-and-found services**.

---

## Basic Project Setup

The initial development environment was prepared for the UniVerse backend.

The setup included:

- Creating the project repository.
- Initializing the Node.js project.
- Setting up the basic backend structure.
- Configuring environment variables using `.env`.
- Installing the required backend dependencies.
- Establishing a connection between the application and **MongoDB using Mongoose**.

### MongoDB Connection

The MongoDB database connection was successfully configured. The connection is handled separately so that the database can be accessed by the backend models as development progresses.

At this stage, no major application functionality was implemented. The focus was on preparing the backend and database foundation.

---

# Data Model Planning

The initial database requirements were analyzed based on the planned features of UniVerse.

The major entities identified were:

- Users
- Skills
- Skill Requests
- Sessions
- Ratings
- Credits / Points
- Lending and Borrowing
- Lost and Found
- Notifications

An **Entity Relationship Diagram (ERD)** was planned to visualize the relationships between these entities and provide a reference for the Mongoose schemas that will be implemented in later stages.

---

# Project Division

The project was divided into **four major modules** to organize development and clearly define responsibilities.

### Part 1 — Authentication & User System

- Registration and Login
- User Profiles
- Authentication
- Skill Setup

### Part 2 — Community Channels

- Channels
- Posts
- Lending
- Borrowing
- Lost and Found
- General Community Features

### Part 3 — Skill Discovery & Matching

- Skill Listings
- Browsing Mentors
- Search
- Filters
- Recommendations
- Mentor Profiles
- Request Creation

### Part 4 — Sessions, Points & Leaderboard

- Accepting Requests
- Session Status
- Completion Confirmation
- Points Transactions
- Reputation
- Leaderboard

---

# Next Steps

The next phase will focus on implementing the planned functionality incrementally.

The immediate priorities are:

1. Finalize the Mongoose schemas.
2. Implement the User model.
3. Implement registration and login.
4. Add authentication middleware.
5. Begin development of the remaining modules.
