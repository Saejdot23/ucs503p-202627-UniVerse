# UniVerse User Discovery Feature - Implementation Journal

**Date:** October 30, 2026  
**Feature:** User Discovery in Skill Swap (I Want to Learn & I Want to Teach)

---

## Summary

A complete end-to-end user discovery feature has been successfully implemented for the UniVerse Skill Swap platform. This feature allows students to discover potential mentors (in "I Want to Learn" mode) and learners (in "I Want to Teach" mode) through a new "Users" tab, complementing the existing skills-based discovery.


## Backend Implementation

### 1. New Controller Functions

**File:** `code/backend/src/controllers/skill.controllers.js`

Two new async controller functions added:

#### `learnDiscoveryUsers(req, res)`
Returns users who have skills to teach (mentors).

#### `teachDiscoveryUsers(req, res)`
Returns users who have skills they want to learn (potential learners).

**Key Difference:** Returns `skillsToLearn` instead of `skillsToTeach`  
All other logic identical to `learnDiscoveryUsers`

### 2. New Routes

**File:** `code/backend/src/routes/skill.routes.js`

Two new route definitions added **before** the `/:id` catch-all route:

```javascript
router.route("/teach-discovery-users").get(teachDiscoveryUsers)
router.route("/learn-discovery-users").get(learnDiscoveryUsers)
```

**Route Characteristics:**
- Require JWT authentication (inherited from `router.use(verifyJWT)`)
- Placed strategically before `/:id` to prevent `:id` from matching
- Support query params: `?q=search&page=1&limit=20`

### 3. Database Query Strategy

Uses MongoDB aggregation pipeline for optimal performance.


## 🎯 Feature Highlights

### For Students (I Want to Learn)
- Discover mentors by name search  
- See what each mentor teaches at a glance (skill count)  
- Judge mentor quality via ratings  
- Quick profile access to learn more  

### For Students (I Want to Teach)
- Discover potential learners by name  
- See what each learner needs (skill count)  
- Identify engaged learners via ratings  
- Quick profile access for compatibility assessment  

### For Platform
- Improved peer discovery mechanism  
- Quality-first matching (best-rated users first)  
- Efficient server-side queries  
- Consistent tab-based UX  
- Full accessibility support
