# Contribution: Reusable UI Component Library
  
**Commit Message:** `feat(ui): add reusable UI component library`  
**Date:** September 18, 2026

---

## 1. Overview

Added a reusable UI component library for the UniVerse frontend to provide common interface elements and consistent handling of loading, error, empty, avatar, and rating states.

---

## 2. Components Added

### 2.1 Avatar Component

Added an `Avatar` component for displaying user profile images.

Features:

- Supports user profile images.
- Provides an initials fallback when an image is unavailable.

This makes user identity displays reusable across different parts of the application.

---

### 2.2 ErrorState Component

Added an `ErrorState` component for displaying error messages.

The component provides a reusable way to represent error conditions instead of requiring individual pages to implement their own error UI.

---

### 2.3 EmptyState Component

Added an `EmptyState` component for cases where there is no content or data to display.

It can be reused in situations such as:

- No saved posts
- No search results
- No messages
- No available content

---

### 2.4 LoadingSpinner and PageLoader Components

Added two reusable loading components:

- `LoadingSpinner` — for smaller or localized loading states.
- `PageLoader` — for page-level or larger loading states.

These components allow loading behavior to be reused across different pages and features.

---

### 2.5 StarRating Components

Added two components for rating functionality:

- `StarDisplay` — displays an existing star rating.
- `StarPicker` — allows a user to select a star rating.

These components provide reusable building blocks for rating-related functionality in the application.

---

## 3. Technical Purpose

The main purpose of this change was to centralize commonly used UI elements into reusable components.

Instead of implementing separate versions of the same UI behavior in different pages, the application can reuse the shared components for:

- User avatars
- Loading states
- Error states
- Empty states
- Star ratings

This reduces repeated code and makes these common UI elements easier to maintain and reuse.

---

## 4. Result

The commit established a reusable UI component foundation for the UniVerse frontend.

The newly added components can be imported and used by other pages and features as required, providing a consistent implementation for common interface states and elements.
